# Security

Sphere runs coding agents on your machine with your account, so we take security reports seriously.

Please **don't open a public issue** for a vulnerability. Report it privately through GitHub's
[security advisories](https://github.com/xiaojia630/sphere/security/advisories/new) instead. Include what you found,
how to reproduce it, and what it could let someone do. You'll get a reply within a few days.

Sphere is pre-1.0: fixes land on `main` and in the next release.
